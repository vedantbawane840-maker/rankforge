Quickstart Guide

IDE Setup & MCP Integration

Connect RankForge's server-side Beyond SEO engine to your AI coding assistant in 5 simple steps.

The 5-Step Integration Workflow

Step 1

Sign Up

Create an account at rankforge.app

Step 2

BYOK Apify

Save your personal key in the dashboard

Step 3

Copy URL

Copy your custom authenticated MCP endpoint

Step 4

Paste Config

Paste JSON into Cursor, Claude, or Windsurf

Step 5

Prompt Agent

Ask: "audit my website for SEO & AEO"

IDE-Specific Configurations

1. Cursor

JSON Config

Add the following block to .cursor/mcp.json in your project workspace or global user settings:

.cursor/mcp.json 
{
  "mcpServers": {
    "rankforge": {
      "url": "https://rankforge-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}

2. Claude Code

CLI & JSON

Option A: Direct CLI Command:

Terminal Command 
claude mcp add --transport http rankforge https://rankforge-mcp.workers.dev/mcp --header "Authorization: Bearer YOUR_JWT_TOKEN"

Option B: In claude_desktop_config.json:

claude_desktop_config.json 
{
  "mcpServers": {
    "rankforge": {
      "url": "https://rankforge-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}

3. Windsurf

JSON Config

Add to ~/.codeium/windsurf/mcp_config.json:

mcp_config.json 
{
  "mcpServers": {
    "rankforge": {
      "serverUrl": "https://rankforge-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}

4. Cline

JSON Config

Add to cline_mcp_settings.json with pre-configured auto-approval for smooth agent autonomy:

cline_mcp_settings.json 
{
  "mcpServers": {
    "rankforge": {
      "url": "https://rankforge-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      },
      "disabled": false,
      "autoApprove": [
        "seo_audit",
        "keyword_research",
        "competitor_analysis",
        "backlink_audit",
        "local_seo",
        "aeo_geo_audit",
        "technical_seo",
        "generate_report"
      ]
    }
  }
}

5. Zed

Context Server

Add to Zed's settings.json under context_servers:

settings.json 
{
  "context_servers": {
    "rankforge": {
      "url": "https://rankforge-mcp.workers.dev/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}

6. OpenAI Codex / Custom GPT Actions

REST / Actions

Configure as a custom GPT Action using Bearer token authentication:

Custom Action Setup 
1. Navigate to GPT Configuration -> Actions -> Create New Action
2. Import Schema URL:
   https://rankforge-mcp.workers.dev/tools
3. Authentication -> API Key -> Auth Type: Bearer
4. Set Token to: YOUR_JWT_TOKEN (found on your dashboard)

MCP Tool Catalog & Schemas

seo_audit Core Tool

Runs comprehensive 100-point SEO audit including metadata, on-page content, CWV performance indicators, and structural tags.

Example Prompt: "Run an SEO audit on https://myapp.com and list top recommendations"
aeo_geo_audit AI Search Engine

Evaluates content citation probability for generative engines like Perplexity, ChatGPT Search, and Google Gemini.

Example Prompt: "Audit my landing page for AEO citation potential on Perplexity"
keyword_research Clustering

Performs intent classification, search volume estimation, and topical clustering for targeted seed keywords.

Example Prompt: "Find low-competition keywords related to 'mcp server for agents'"
competitor_analysis Intelligence

Analyzes keyword overlap, content gaps, and ranking disparities between your domain and competitors.

Example Prompt: "Analyze competitor keyword gaps between mydomain.com and competitor.com"
